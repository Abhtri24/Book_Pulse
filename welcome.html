Welcome to BookPulse

BookPulse is a FastAPI‑based platform for managing and analysing reading activity. It provides:

  • CRUD operations for books, authors, chapters and text snippets.
  • User authentication with JWT access and refresh tokens.
  • Engagement tracking – readers can log reading events and the system records metrics.
  • Feedback collection on snippets and overall reading experience.
  • Automated classification of snippets using a GROQ language model.
  • Dashboard endpoints that expose aggregated statistics for books and readers.

The application stores data in a PostgreSQL database (SQLAlchemy async) and uses Redis/Celery for background tasks. It is containerised with Docker and includes Alembic migrations for schema evolution.

Explore the API documentation at /docs after starting the server.
